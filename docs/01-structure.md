# ТЗ и структура — редизайн «Презентация для ФСИ»

## Рабочее ТЗ (10 полей)

| Поле | Значение |
|---|---|
| 1. Тип | Презентация грантового проекта для ФСИ (pitch deck для фонда) |
| 2. Главная цель | Показать проект C1-643128: суть, готовность, рынок, команду — чтобы ФСИ/партнёры видели зрелость концепции |
| 3. Аудитория | Эксперты и менеджеры ФСИ, потенциальные партнёры (вузы, клиники), технически подкованные, консервативные |
| 4. Продукт | MR/VR-платформа обучения и автоматизированной оценки проводниковой анестезии в стоматологии |
| 5. Ключевая ценность | Безопасная отработка навыка на физическом манекене с цифровой анатомией и объективной оценкой |
| 6. Ключевые смыслы | Боль (осложнения у новичков), решение (смешанная реальность), точность (1 мм, TauTracker), 3 режима, рынок от 1,5 млн ₽, задел и план до регистрации ПО 2027 |
| 7. Факты | 2–4× чаще осложнения; 5,4–14,7% при стаже <2 лет; 60–75% технические; точность ≤1 мм, задержка ≤50 мс; рынок $401,8→701,1 млн; оборот 735→1120 млрд ₽ |
| 8. Ограничения | Не обещать клиническую эффективность; «образовательный инструмент, не для диагностики/лечения»; депонирование РЦИС — факт, не гарантия |
| 9. Формат | 16:9, HTML + PDF, 14 слайдов |
| 10. CTA | Показать готовность к НИОКР; следующий шаг — регистрация ПО (3 кв. 2027) и партнёрство/поставки |

## Структура слайдов

Порядок: обложка → боль → решение → продукт → доказательства → рынок → план → команда.

| № | Функция | Заголовок | Ключевая мысль | Доказательство | Визуал |
|---|---|---|---|---|---|
| 1 | Обложка | XR-тренажёр проводниковой анестезии | Проект C1-643128: MR/VR-обучение мануальным навыкам | № РЦИС, руководитель, 2026 | Неоновая XR-сцена: шлем + голографический череп |
| 2 | Боль | Почему обучение на пациентах и фантомах недостаточно | Осложнения у новичков — техническая проблема | 2–4×; 5,4–14,7%; 60–75% | Неоновая инфографика риска |
| 3 | Решение | Смешанная реальность вместо риска на пациенте | Руки и манекен видны, поверх — цифровая анатомия | MR-режим, безопасность, трекинг | Голография над манекеном |
| 4 | Продукт | Как устроен аппаратно-программный комплекс | Шлем + манекен + шприц-имитатор + TauTracker + ПО | Состав комплекса | XR-стейшн, exploded view |
| 5 | Процесс | Пять шагов от шлема до итоговой оценки | Полный цикл сценария за одну сессию | 5 шагов сценария | Горизонтальный step-timeline |
| 6 | Режимы | Учебный режим, экзамен и вариативность сценариев | Подстройка под задачу преподавателя | Подсказки / самостоятельность / параметры | 3 glass-карточки |
| 7 | Технология | Точность до 1 мм: TauTracker и 6 зон контроля | Цифровая оценка каждого движения | ≤1 мм, ≤50 мс, 6 зон | Игла + траектория, HUD |
| 8 | Преподаватель | Панель контроля учебной сессии | Вид из шлема, этапы, ошибки, роли | 3 роли, управление сценарием | Дашборд преподавателя |
| 9 | Архитектура | Состав прототипа и задел для масштабирования | Аппарат, ПО, эксплуатация, интеграции | ≥2 ч, +10…+30°C, LMS | Схема модулей |
| 10 | Рынок | Кто платит за продукт и почему | 4 сегмента + экономика + размер рынка | $401,8→701,1 млн; 1,5 млн ₽ | Неоновая инфографика-рост |

| 12 | План | Что уже готово и что будет в НИОКР | Задел → прототип → регистрация ПО | Депонирование, 3 кв. 2027 | Timeline / road-map |

## Визуальная концепция

- **Стиль:** тёмный tech-neon, голографическая анатомия, XR-медтех (по референсу Metaverse)
- **Палитра:** фон `#0B0620`, карточки `#151033`, акценты `#8B5CF6` / `#D946EF` / `#22D3EE`, текст `#EDE9FE` / `#A5A0C8`
- **Шрифты:** Unbounded (заголовки) + Manrope (текст)
- **Макеты:** обложка-fullbleed · боль-цифры · продукт-callout · glass-карточки · финал
- **Картинки:** 3D-неон/голография, без текста на изображении
